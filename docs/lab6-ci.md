## Индивидуальная часть

HTML-validate 10.7.0 проверяет HTML по recommended-профилю. Только wcag/h32 отключён: демо-форма специально не имеет настоящей submit-кнопки и защищена CSP form-action none. Это не отключает проверку alt.

Stylelint 16.26.1 проверяет CSS: неизвестные свойства, цвета и единицы, дубли деклараций и селекторов, неизвестные псевдоклассы/элементы и директивы, пустые блоки. Версии и integrity зависимостей сохранены в package-lock.json.

`check_site.py` проверяет исходник и, отдельно в build, содержимое `_site`: один h1, уникальные id, локальные ссылки и файлы, три фотографии с alt и размерами, защиту формы. Ресурс, не попавший в артефакт, останавливает build до публикации.

`test_quality_gate.py` создаёт временные ошибочные примеры вне проекта: изображение без alt и colro вместо color. Проверяется ненулевой код и нужная диагностика (HTML-validate: 1; Stylelint: 2). Основные файлы при этом не портятся.

`needs` связывает quality → build → deploy. PR выполняет проверки, но не публикуется. Build/deploy разрешён только для main. Права Pages/OIDC выданы лишь deploy; checkout не сохраняет токен. Персональные токены и секреты хостинга не нужны. В публичный артефакт не входят .git, docs и node_modules.

Также локально пройдены 33 браузерные проверки на ширинах 320–1440 px, с JavaScript и без него. Это не полный аудит доступности или безопасности. Реальные снимки сайта до/после, GitHub workflow, успешных запусков и бейджа включены в отчёт и архив ЛР №6.
