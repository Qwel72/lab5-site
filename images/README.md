# Источники фотографий

Изображения скачаны в рабочую папку и подключены по относительным путям. Это иллюстрации космоса, не фотографии клуба. Размер уменьшен до 1000 пикселей, файлы перекодированы в JPEG без изменения содержания.

- `earth-apollo17.jpg` — Земля · Apollo 17. Снимок Земли с борта Apollo 17, 1972 год. Источник: https://www.nasa.gov/image-article/blue-marble-image-of-earth-from-apollo-17/. Кредит: NASA.
- `moon-galileo.jpg` — Луна · Galileo. Луна на снимке аппарата Galileo, 1992 год. Источник: https://images.nasa.gov/details/PIA00405. Кредит: NASA/JPL/USGS.
- `jupiter-voyager2.jpg` — Юпитер · Voyager 2. Снимок Voyager 2, 1979 год; цвета усилены при обработке. Источник: https://science.nasa.gov/image-detail/amf-f8e2e3e3-eba1-48c7-a03c-a9bed0d637fa/. Кредит: NASA/JPL/USGS.

Использование: учебный некоммерческий сайт, с указанием источника; одобрение NASA не подразумевается. Правила NASA: https://www.nasa.gov/nasa-brand-center/images-and-media/ . У этих выбранных материалов указаны NASA и NASA/JPL/USGS, сторонний правообладатель на проверенных страницах не указан.
